
# Microsoft 365 / Entra Helpdesk Lab

Hands-on Microsoft 365, Entra ID, and Tier-1 helpdesk practice covering user administration, application troubleshooting, Outlook, Office 365, and common workplace support tasks.

## 📂 Labs

| #  | Lab                                                                            | Description                                                       |
| -- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| 01 | [User Account Management](./01-User-Account-Management)                        | Create users, reset passwords, and manage account access.         |
| 02 | [Troubleshooting Outlook](./02-Troubleshooting-Outlook)                        | Troubleshoot common Outlook issues.                               |
| 03 | [Troubleshooting Word](./03-Troubleshooting-Word)                              | Diagnose and resolve common Microsoft Word problems.              |
| 04 | [Troubleshooting Excel](./04-Troubleshooting-Excel)                            | Troubleshoot common Microsoft Excel issues.                       |
| 05 | [Outlook Search Troubleshooting](./05-Outlook-Search-Troubleshooting)          | Troubleshoot problems with Outlook search and indexing.           |
| 06 | [Applications Not Opening](./06-Applications-Not-Opening)                      | Investigate and troubleshoot applications that fail to launch.    |
| 07 | [New User Setup – Microsoft 365](./07-New-User-Setup-M365)                     | Practice setting up a new user in Microsoft 365.                  |
| 08 | [Repairing Applications](./08-Repairing-Applications)                          | Practice repairing Microsoft 365 and Windows applications.        |
| 09 | [Deploying Office Add-ins](./09-Deploying-Office-Add-ins)                      | Deploy Office add-ins through Microsoft 365 administration.       |
| 10 | [Creating Distribution Groups](./10-Creating-Distribution-Group)               | Create and manage distribution groups in Exchange.                |
| 11 | [Adding & Removing Mailboxes in Outlook](./11-Adding-Removing-Mailbox-Outlook) | Manage additional mailboxes in Outlook.                           |
| 12 | [Zoom Hosting & Troubleshooting](./12-Zoom-Hosting-Troubleshooting)            | Practice hosting meetings and troubleshooting common Zoom issues. |
